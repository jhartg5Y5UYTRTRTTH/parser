# LAKES TEAM — Telegram NFT Owner / Market Finder

Бот теперь умеет вести **автоматическую ленту в Telegram-канале**: примерно раз в минуту находит нового публичного владельца/продавца коллекционного подарка и публикует красивую карточку **LAKES TEAM** с кнопками на NFT, профиль и чат.

## Источники

1. **Официальный Telegram Market** — `payments.getStarGifts` + `payments.getResaleStarGifts`. Тут показывается только подарок, который реально находится в Telegram resale-маркете; если Telegram отдаёт цену, бот показывает Stars/TON.
2. **Обычный Telegram NFT** — случайные публичные `t.me/nft/Slug-Number` через `payments.getUniqueStarGift`. Здесь человек является публичным владельцем на момент проверки, но подарок не обязательно продаётся.

Режим `mix` чередует оба источника. Повторы владельцев и подарков не публикуются, пока не выполнить `/reset`.

## Что нужно

- Python 3.10+
- Бот от @BotFather
- `API_ID` и `API_HASH` с `my.telegram.org`
- Личный Telegram-аккаунт для MTProto-запросов подарков
- Канал, в котором бот добавлен администратором с правом **Post Messages**

## Установка

```bash
cd nft_owner_finder
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env
# Linux/macOS: cp .env.example .env
```

Заполни `.env`, затем:

```bash
python auth.py
python bot.py
```

`auth.py` запускается один раз и авторизует **твой обычный Telegram-аккаунт** локально в терминале. Никому не отправляй `.env` и `sessions/`.

## Быстрая настройка канала

В личке с ботом:

```text
/channel @my_channel
/source mix
/interval 12
/autopost on
/postnow
/status
```

Если `/postnow` пишет, что бот не может публиковать — добавь его администратором канала и дай право публикации сообщений.

## Premium-стикеры

В проекте нет украденных/перезалитых ассетов. Бот умеет повторно использовать любой Telegram-стикер, который ты сам пришлёшь ему:

1. Открой `@PremiumStickers` и выбери Premium-стикер.
2. Пришли/перешли этот стикер своему боту.
3. Ответь на сообщение со стикером командой `/setsticker`.
4. `/stickerevery 5` — стикер после каждого пятого NFT-поста; `/stickerevery 1` — после каждого.
5. `/sticker off` отключает его.

Если конкретный Premium-стикер Telegram не разрешит отправить ботом в канал, основной NFT-пост всё равно будет опубликован, а ошибка стикера останется только в логе.

## Команды

- `/channel @channel` — канал автопоста
- `/autopost on|off`
- `/postnow` — тестовый пост прямо сейчас
- `/source mix|market|telegram`
- `/interval 12` — 12 секунд между постами, то есть примерно 5 постов в минуту
- `/rate 5` — выставить скорость 5 постов в минуту
- `/status`
- `/market` — один продавец из Telegram Market в личку
- `/random [Коллекция] [1–3]` — обычный публичный владелец
- `/list`, `/add`, `/remove`, `/reset`
- `/setsticker`, `/sticker on|off`, `/stickerevery N`, `/clearsticker`

## Важные ограничения

- Бот не пишет найденным людям автоматически. Кнопка «Написать продавцу» только открывает чат и подставляет черновик — пользователь сам решает, отправлять его или нет.
- Скрытые владельцы, TON-кошельки, каналы и пользователи без публичного `@username` пропускаются.
- Telegram может вернуть `FLOOD_WAIT`; бот не пытается обходить лимиты и продолжит позже.
- Для source=`telegram` владелец **не обязательно продавец**.
- Рынок и схема MTProto меняются, поэтому держи Telethon обновлённым: `pip install -U telethon`.

## Кнопка «✅ Написал мамонту» в канале

У каждого NFT-поста, который бот публикует именно в настроенный канал, есть четвёртая callback-кнопка:

`✅ Написал мамонту`

При нажатии владельцем бота (`ADMIN_ID`) пост с этим человеком удаляется из канала. Для безопасности подписчики канала нажать кнопку могут, но удалить пост не смогут — им показывается уведомление, что кнопка только для команды.

Чтобы удаление работало, у бота в канале должны быть права администратора на публикацию **и удаление сообщений**.


## Платный доступ на 24 часа

В версии v2.3 бот может продавать временный доступ в **закрытый канал**:

1. Пользователь пишет боту `/start` или `/buy`.
2. Бот выставляет счёт в **Telegram Stars (XTR)**.
3. Только после `successful_payment` в SQLite добавляется подписка на 24 часа.
4. Пользователь получает персональную ссылку с **join request**. Бот одобрит заявку только тому Telegram ID, который оплатил доступ.
5. По окончании времени бот делает `banChatMember` + `unbanChatMember`: пользователь удаляется из канала, но может оплатить ещё 24 часа и зайти снова.
6. Если оплатить несколько раз до окончания срока, оплаченные 24-часовые периоды складываются.

### Права бота в закрытом канале

Нужны права администратора:

- публикация сообщений;
- удаление сообщений;
- приглашение пользователей / управление ссылками;
- блокировка пользователей (Ban Users / Restrict Members).

В `.env`:

```env
ACCESS_PRICE_STARS=50
PAY_SUPPORT_CONTACT=@your_username
```

Админ-команды:

```text
/price 50
/subs
/grant 123456789 60
/revoke 123456789
```

`/grant` нужен, если ты вручную подтвердил оплату вне бота: бот сам банковские переводы не проверяет. Для продажи цифрового доступа **внутри Telegram** используется Telegram Stars.

После обновления зависимостей снова выполни:

```bash
pip install -r requirements.txt
```

Платёжная база хранится в том же `seen.sqlite3`: таблицы `subscriptions`, `payments` и `access_invites`. Не удаляй этот файл при обновлении, если хочешь сохранить оплаченный доступ.
